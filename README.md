# AI Recruiting Assistant

An AI-powered recruiting inbox for college coaches.

## Overview

College coaches receive hundreds of recruiting emails from prospective student-athletes.

This platform automatically:

- Reads recruiting emails
- Extracts player information
- Stores prospect profiles
- Scores prospects against coach recruiting needs
- Provides a searchable dashboard
